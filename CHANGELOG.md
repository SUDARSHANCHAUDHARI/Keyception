# Changelog

All notable user-facing changes to Keyception are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Three-stage drag-and-drop key puzzle with increasingly strange keys and locks.
- Eight shuffled anomaly events plus authored drawer and smaller-door transitions.
- Pointer, touch, pen, and keyboard interaction with forgiving collision detection.
- Generated Web Audio effects with an in-session sound toggle.
- Responsive layout, progress indicators, reset controls, live announcements, visible
  focus states, forced-color support, and reduced-motion behavior.
- Dependency-free validation and production build commands.
- Browser Content Security Policy and repository security guidance.
